# 🏥 Healthcare Patient Churn Analysis & Retention Insights

## 📌 Project Overview

Patient retention is an important challenge for healthcare organizations. Understanding why patients leave can help organizations improve patient experience, accessibility, engagement, and retention strategies.

This project focuses on analyzing a healthcare patient dataset to identify patterns and factors associated with **patient churn**.

The project uses **Python for data cleaning and exploratory data analysis (EDA)**, **SQL for analytical querying**, and **Power BI for interactive visualization and dashboard development**.

The analysis also includes feature engineering to create an **Engagement Score** that helps classify patients according to their level of engagement.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Understand the structure and quality of the healthcare dataset.
- Analyze patient demographics and healthcare utilization.
- Calculate and understand the overall churn rate.
- Identify factors associated with patient churn.
- Analyze patient engagement and appointment behavior.
- Compare churn across different age groups, genders, insurance types, specialties, and locations.
- Examine the relationship between billing issues and patient churn.
- Analyze the impact of distance from the healthcare facility.
- Create meaningful patient engagement segments.
- Build an interactive Power BI dashboard.
- Generate actionable business insights and retention recommendations.

---

## 🗂️ Dataset

The dataset contains information about **2,000 patients** with **21 original columns**.

### Key Attributes

| Category | Attributes |
|----------|------------|
| Patient Information | Patient ID, Age, Gender, State |
| Healthcare Usage | Visits Last Year, Missed Appointments, Days Since Last Visit |
| Patient Relationship | Tenure Months |
| Healthcare Services | Specialty, Insurance Type |
| Satisfaction | Overall Satisfaction, Wait-Time Satisfaction, Staff Satisfaction, Provider Rating |
| Financial | Average Out-of-Pocket Cost, Billing Issues |
| Accessibility | Distance to Facility |
| Digital Engagement | Portal Usage |
| Advocacy | Referrals Made |
| Target Variable | Churned |

`Churned` is the target variable:

- `1` → Patient churned
- `0` → Patient retained
